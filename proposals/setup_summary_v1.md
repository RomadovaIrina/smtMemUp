# Постановка эксперимента: версия 1 (Stack, без шума)

Справка для научника, 14.10.2026. Код: `smt_memup_stack.py`. Запуск: `runs/stack02_4c69a2819ab8`.
Предрегистрация: `runs/stack02_4c69a2819ab8/preregistration.md`.

## Данные
Генератор авторов SMT (`StackDataset`):
* Последовательность из 64 операций, значения 1–4, глубина стека ≤ 8.
* Словарь 5 токенов: 0 — pop, 1–4 — push значения. Если возможны оба действия, push и pop выбираются 50/50.
* Ответ есть только на pop — это извлечённое значение. В среднем около 30 ответов на последовательность.
* «Дальний» ответ — давность ≥ 8 шагов (в Stack давность нечётная, то есть ≥ 9). Таких около 15%.
* Угадывание наугад — 25%.

## Объём данных
Обучающие данные генерируются заново на каждом шаге, повторов (эпох) нет.

| набор | объём | для чего |
|---|---|---|
| обучение SMT | 3000 шагов × 32 = 96 000 последовательностей; в каждой все 64 момента t, т.е. 2048 окон на шаг | обучение teacher и RNN |
| обучение DMT | 1500 шагов × 32 = 48 000 последовательностей | дообучение RNN |
| детекторы неожиданности | 2000 шагов × 32 = 64 000 последовательностей | — |
| validation | 512 последовательностей: 15 344 ответа, 2275 дальних | выбор checkpoint (оценка каждые 250 шагов) |
| tuning | 512 последовательностей: 15 377 ответов, 2359 дальних | gate baseline и подбор α |
| test | 2048 последовательностей: ≈ 61 тыс. ответов, ≈ 9 тыс. дальних | создаётся один раз после всех обучений; пересечения с другими наборами проверяются |

## Архитектура
Классы из репозитория авторов SMT без изменений; размеры выбраны нами.

| часть | у нас | у авторов по умолчанию (TinyStories / MNIST) |
|---|---|---|
| энкодер teacher | двунаправленный Transformer, 3 слоя, d = 64, 4 головы, rotary, RMSNorm | 8 слоёв, d = 256, 8 голов |
| память m_t | 8 токенов × 64 = 512 чисел, RMSNorm | 16 × 256 = 4096 |
| декодер teacher | каузальный Transformer, 2 слоя; вход — память и будущие входы x_{t+1..} | 4 слоя |
| RNN (updater) | Transformer, 2 слоя, над [8 токенов памяти + 1 входной токен] → новая память | 8 слоёв |
| readout RNN | копия декодера teacher | 4 слоя |
| параметры | teacher 0,50 млн, RNN 0,40 млн | 12,6 млн и 12,6 млн |

## Обучение
**SMT**
* 3000 шагов, батч 32 последовательности, все моменты t; Tc = Tf = 64 (как у авторов для синтетики).
* AdamW, lr 3e-4, betas (0,9; 0,95), weight decay 0,01.
* Разогрев 200 шагов, затем косинус до 0,1×; ограничение нормы градиента 1; fp32.
* Loss авторский: L_dec + 0,1·L_dyn + 0,001·L_unif, плюс α·L_sel у вариантов с отбором.

**DMT**
* 1500 шагов, батч 32, lr 1e-4 с тем же расписанием; teacher заморожен.
* RNN разворачивается от нулевого состояния по всей последовательности, без градиента между шагами.
* Loss: 10·MSE до состояний teacher плюс CE readout (учит только голову).

**Выбор checkpoint**
* Оценка на validation каждые 250 шагов.
* SMT — лучшая CE teacher на дальних ответах; DMT — лучшая CE RNN.
* Последние веса тоже сохраняются (проверка устойчивости).

## Варианты и отбор
* Основное сравнение: baseline, uniform, random-K, surprise-K.
* Доп. диагностика: surprise-K по входам декодера и oracle.
* K = 4; детектор неожиданности — GRU по последним 8 токенам (окно r = 8).
* α подбирался по сетке {0,1; 0,3; 1} на seed 107. Все варианты выбрали 1,0 — край сетки.
* Финал: seeds 7 / 17 / 27.
* Gate baseline пройден: на дальних ответах teacher 38%, RNN 41% (пороги 35% / 30%).
* Одно обучение ≈ 25 мин на RTX 5090, пик памяти ≈ 7,7 ГБ.

* **Проверка сходимости** (`proposals/stack_convergence_check.md`): тот же baseline на 30 000 шагов SMT и отдельно DMT на 6000 шагов.
  Она нужна потому, что все 26 законченных обучений ещё не вышли на плато: лучший checkpoint у всех — последний или предпоследний шаг.
