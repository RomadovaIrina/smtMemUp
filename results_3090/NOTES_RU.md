# Результаты очередей на RTX 3090 (с 25.10.2026): происхождение и известные проблемы

* **Источник.** Содержимое папки — копия `~/smt_memup_project/results/` с сервера (команда `bash sync_results.sh`).
  Чекпойнты (`*.pt`) не копируются, они остаются на сервере.
* **Код.** Все запуски сделаны ноутбуком `SMT_MemUP_FROM_ZERO.ipynb` (версия 1) через `run_experiments.py`.
  Запуски на ячейке Zoology идут через `zoology_cell/run_cell.py`.

## Известные проблемы
1. **Упавшие запуски (OOM).** 25.10 около 17:07–17:14 семь заданий упали по нехватке памяти GPU, когда параллельно
   шли два тяжёлых SMT-задания Stack:
   * `mqar_T32N4_smt` — сиды 202, 203;
   * `stack_bptt_full` — сиды 202, 203;
   * `stack_bptt_1` — сиды 201, 202, 203.

   Их каталоги без `summary.json` сохранены как свидетельство и в графиках не используются. Эти задания поставлены
   заново, уже с ожиданием свободной памяти перед стартом.
2. **Потеря части истории SMT у двух запусков.** 25.10 в 21:19 код на сервере обновлялся через `git pull`, а в ветке
   уже лежали синхронизированные результаты. `pull` перезаписал живые файлы старыми копиями. В
   `stack_smt_tf8_s203_20261025-185726_693936` и `stack_smt_tf8_ctx_far_s201_20261025-185732_693987` файл
   `smt_history.csv` содержит строки только до шага 6500. SMT-стадия к тому моменту закончилась, и файл больше не
   перезаписывался.
   * **Не затронуто:** итоговые числа (`summary.json`: выбранный и последний чекпойнт), история DMT и все остальные
     запуски (у них файлы перезаписались идентичными копиями).
   * **Чтобы это не повторилось:** на сервере результаты сняты с отслеживания git, локальная копия лежит в
     `results_3090/`, сервер эту папку не использует. Резервная копия на сервере — `~/smt_results_backup_2124`.
3. **Абляции Stack** (`no_dyn`, `target_detached`, `fully_detached`) — только сид 201 (решение 25.10). Основные
   сравнения — сиды 201–203.
4. **Ячейка Zoology остановлена** (решение 25.10, 23:50): очередь смесителей и запуск `ours_smt` прерваны, считаем
   только Stack и MQAR T16/T32. Частичные логи в `zoology_cell/` — незавершённые запуски, в выводах не используются.
5. **Full BPTT на MQAR T16N2 (6000 шагов) не сошёлся:** у сидов 202/203 валидация на плато ~50% с шага 1500, у
   сида 201 ещё растёт (38%). Поэтому 45,2% — не потолок модели. Поставлены `mqar_T16N2_rnn_bptt_full_long` и
   `mqar_T32N4_rnn_bptt_full_long`: 60 000 шагов, ранняя остановка на 99%, сиды 201–203.
6. **OOM 26.10 07:03:** `stack_smt_tf8_surprise_far` seed 201 упал при старте. Параллельно шла абляция
   `fully_detached`, она заняла 16 ГБ вместо ожидаемых ~9. Каталог без `summary.json` сохранён, запуск поставлен заново.
